## 一、信用风险与评分卡业务概念

### 1.1 评分卡（Scorecard）
一种用**分数**表示客户信用风险的模型。不是直接输出违约概率，而是把概率换算成 300–900 区间的整数分，分数越高越安全。
本项目做的是 **A 卡（Application Scorecard，申请评分卡）**：在新客户/新报告期进件时打分。

| 卡类型 | 时点 | 用途 |
|---|---|---|
| A 卡 | 贷前申请 | 审批、额度 |
| B 卡 | 贷中行为 | 调额、预警 |
| C 卡 | 贷后催收 | 催收优先级 |

### 1.2 违约概率 PD（Probability of Default）
未来一段时间内借款人发生违约的概率。本项目预测窗口 = **未来 1 年**。

### 1.3 Odds（几率/赔率）
```
odds = P(违约) / P(不违约) = p / (1-p)
```
评分卡刻度的桥梁变量：分数与 log(odds) 呈线性关系。

### 1.4 ST / *ST / PT / 暂停上市
A 股的风险警示制度，本项目用它作为**上市企业"违约"的代理事件**（真实债券违约数据稀缺）：
- `STPT = 1`：被特别处理（ST / *ST / PT）
- `IsSuspend = 1`：暂停上市
- 二者任一发生 → 定义为 **distressed（财务困境/违约）**

### 1.5 违约率（Default Rate）
```
default_rate = 违约样本数 / 总样本数
```
本项目面板约 2.92% —— 典型的**类别不平衡**问题，是逻辑回归 `class_weight="balanced"` 和 LGBM `scale_pos_weight` 的设置依据。

## 二、目标变量（标签）的构造

### 2.1 `is_distressed`（当年是否困境）
```
is_distressed = 1  if STPT == 1 or IsSuspend == 1  else 0
```

### 2.2 `is_default_next_year`（核心标签）
用 **t 年财务特征** 预测 **t+1 年是否困境**，避免"用违约当年来解释违约"的时序穿越：
```
is_default_next_year(t) = is_distressed(t+1)      # groupby(Symbol).shift(-1)
```
特征年范围 2015–2024，标签年范围 2016–2025。

## 三、模型所需变量字段（财报信息，源自 CSMAR）

### 3.1 偿债能力（Solvency）

| 字段 | 中文名 | 公式 | 经济含义 |
|---|---|---|---|
| `CurrentRatio` | 流动比率 | 流动资产 / 流动负债 | 短期偿债能力，≥1 为安全线 |
| `QuickRatio` | 速动比率 | (流动资产 − 存货) / 流动负债 | 剔除变现慢的存货 |
| `CashRatio` | 现金比率 | 货币资金 / 流动负债 | 最保守的即期偿付能力 |
| `DebtToAsset` | 资产负债率 | 总负债 / 总资产 | 长期杠杆水平，越高违约风险越大 |

### 3.2 盈利能力（Profitability）

| 字段 | 中文名 | 公式 | 经济含义 |
|---|---|---|---|
| `ROA` | 总资产收益率 | 净利润 / 总资产 | 每单位资产的盈利效率 |
| `ROE` | 净资产收益率 | 净利润 / 股东权益 | 股东回报率，可被杠杆放大 |
| `GrossMargin` | 毛利率 | (营收 − 营业成本) / 营收 | 产品附加值与定价能力 |
| `NetProfitMargin` | 净利率 | 净利润 / 营业收入 | 每元收入的最终盈利 |

### 3.3 经营能力（Activity / Efficiency）

| 字段 | 中文名 | 公式 | 经济含义 |
|---|---|---|---|
| `AR_Turnover` | 应收账款周转率 | 营业收入 / 应收账款 | 回款速度，低 = 赊销激进、坏账风险 |
| `Inventory_Turnover` | 存货周转率 | 营业成本 / 存货 | 存货变现速度，低 = 滞销 |
| `TotalAsset_Turnover` | 总资产周转率 | 营业收入 / 总资产 | 资产使用效率（杜邦分析核心项之一） |

### 3.4 发展能力（Growth）

| 字段 | 中文名 | 公式 | 注意事项 |
|---|---|---|---|
| `TotalAsset_Growth` | 总资产增长率 | (本期 − 上期) / 上期 | ⚠️ CSMAR 原字段是**单季度环比**，非年度同比，使用需谨慎 |
| `NetProfit_Growth` | 净利润增长率 | (本期 − 上期) / 上期 | 同上；利润基数小时波动极大 |
| `Revenue_Growth` | 营收增长率 | (本期 − 上期) / 上期 | 同上 |

### 3.5 现金流（Cash Flow）

| 字段 | 中文名 | 公式/来源 | 经济含义 |
|---|---|---|---|
| `CashFlow1` | 经营现金流相关指标 | CSMAR F061301B | 经营活动产生的现金净流入能力 |
| `FCF` | 自由现金流 | 经营现金流 − 资本支出 | 偿债与分红的"真金白银" |

> 偿债看利润是"面子"，看现金流是"里子"。违约企业普遍存在"有利润、无现金"的特征。

### 3.6 规模与负债结构（v2 特征工程产物）

| 字段 | 公式 | 说明 |
|---|---|---|
| `ln_TotalAssets` | ln(总资产)，仅对 >0 取值 | 取对数压缩右偏分布，规模效应 |
| `ln_OperatingRevenue` | ln(营业收入) | 同上 |
| `FinancialDebtRatio` | 金融负债 / 总资产 | 有息负债率（银行借款、债券），**刚性**偿债压力 |
| `OperatingDebtRatio` | 经营负债 / 总资产 | 应付账款等无息占款，属**软性**负债 |

> 区分"刚性负债"与"经营占款"是信用分析的关键：同样 60% 资产负债率，金融负债占 50% 远比经营负债占 50% 危险。

### 3.7 控制变量（非财报）

| 字段 | 中文名 | 说明 |
|---|---|---|
| `IndustryCode` / `IndustrySector` | 行业代码 / 行业大类 | CSMAR 行业码前两位（GB/T 4754），用于行业分组与剔除金融业 |
| `Ucsp` | 实际控制人类型 | 国资/民营/外资等，含 "1,2" 多重控制，作分类变量 |
| `ContrshrProportion` | 控股股东持股比例 | 股权集中度 |
| `Province` | 注册省份 | 区域宏观差异 |
| `FirmAge` | 企业年龄 | `year − ListYear`（上市年数），幼年期企业死亡率高 |
| `Symbol` / `ShortName` / `EndDate` / `year` | 股票代码 / 名称 / 报告期 / 年份 | 标识列，建模前剔除 |

## 四、特征工程术语（v2）

### 4.1 行业相对特征（Industry-Relative Features）
跨行业财务比率不可比（如钢铁业负债率天然高于软件业）。做法：
```
X_industry_dev = X_company − median(X | year, IndustrySector)
```
应用于：DebtToAsset、CurrentRatio、ROA、ROE、GrossMargin、NetProfitMargin、TotalAsset_Turnover。
含义：**公司在同行业同年内的相对位置**，比绝对值更有区分力。

### 4.2 滚动时序特征（Rolling Window Features）
```
X_3y_avg = mean(X[t-3], X[t-2], X[t-1])     # 前三年均值：趋势水平
X_3y_std = std(X[t-3], X[t-2], X[t-1])      # 前三年标准差：波动性
```
关键细节：`shift(1)` 后再滚动，**严格只用历史期**，防止时序穿越。
应用于：DebtToAsset、ROA、OperatingRevenue、ln_TotalAssets、CurrentRatio。
> std 大 = 盈利/杠杆不稳定，本身就是风险信号。

### 4.3 Winsorize（缩尾/盖帽）
```
X' = clip(X, Q(0.01), Q(0.99))
```
把低于 1% 分位、高于 99% 分位的值截断到分位点。与删除不同：样本保留，只压极端值。
应用：17 个核心数值特征，按全样本分位处理。

### 4.4 交互特征（Interaction Feature）
```
ROA_x_Turnover = ROA × TotalAsset_Turnover
```
近似"净利润率 × 周转率"的杜邦分解思路：盈利高但周转慢，未必健康。

### 4.5 样本筛选
- **合并报表 + 年报**：`Typrep="A"`、`EndDate` 以 `-12-31` 结尾——排除母公司报表和季报，保证口径一致。
- **剔除金融业 J6\***：金融业（银行/券商/保险）的资产负债结构（高杠杆是经营模式）与实体企业不可比，财务比率指标失效，故整体剔除。

## 五、统计建模方法与量化模型

### 5.1 变量筛选（var_filter）
三重过滤，剔除无预测力的变量：

| 过滤器 | 阈值 | 依据 |
|---|---|---|
| IV 下限 | ≥ 0.02 | 预测力太弱 |
| 缺失率上限 | ≤ 0.5 | 缺失过多不可靠 |
| 单一值占比上限 | ≤ 0.95 | 变量近乎常数，无区分度 |

### 5.2 WOE（Weight of Evidence，证据权重）
分箱后，每箱的 WOE：
```
WOE_i = ln( Bad_i / Bad_total ) − ln( Good_i / Good_total )
      = ln( 分布坏客户占比 / 分布好客户占比 )
```
- WOE > 0：该箱坏客户占比高于平均 → 风险更高
- 作用：① 把任意分布统一到对数几率尺度；② 吸收非线性；③ 缺失值/异常值自成箱；④ 让 LR 系数可直接解释

### 5.3 IV（Information Value，信息值）
```
IV = Σ_i ( Bad_i/Bad_total − Good_i/Good_total ) × WOE_i
```
变量级预测力评估（业界经验）：

| IV 区间 | 预测力 |
|---|---|
| < 0.02 | 几乎无用（被 var_filter 剔除） |
| 0.02–0.1 | 弱 |
| 0.1–0.3 | 中等 |
| 0.3–0.5 | 强 |
| > 0.5 | 可疑，警惕标签泄漏 |

本项目测试集实测：`duration_in_month` IV=0.265、`credit_amount` IV=0.201（中等强度，合理）。

### 5.4 监督分箱（Supervised Binning）
`woebin(method="tree")`：用决策树找最优切分点，使各箱之间坏账率差异最大化。约束：最多 8 箱、每箱 ≥5% 样本（保证统计稳定性）。
其他可选方法：`chimerge`（卡方合并）、`quantile`（等频）、`equal`（等宽）。

### 5.5 逻辑回归（Logistic Regression）——主模型
对数几率线性模型：
```
logit(p) = ln( p/(1-p) ) = β₀ + β₁·WOE₁ + β₂·WOE₂ + ... + βₖ·WOEₖ

p = 1 / (1 + e^(−(β₀ + βᵀx)))       # sigmoid 逆映射
```
- 输入：WOE 化后的特征 → 系数符号自动与风险方向一致（WOE 越高风险越大 → 系数应为负贡献好分）
- 输出：违约概率 p

**关键参数**：

| 参数 | 本项目取值 | 含义 |
|---|---|---|
| `penalty` | l2 | L2 正则，惩罚大系数，防过拟合 |
| `C` | 1/λ = 1/0.01 = **100** | 正则强度倒数；C 越大正则越弱。⚠️ 0.01 的 λ 实际约束很弱 |
| `solver` | liblinear / lbfgs | 小数据用 liblinear，面板大数据用 lbfgs |
| `max_iter` | 1000 | 最大迭代次数 |
| `class_weight` | "balanced" | 权重 = n_samples / (n_classes × count)，补偿 2.9% 违约率的类别不平衡 |

### 5.6 评分卡刻度换算（Score Scaling）
把 log-odds 线性映射到分数。行业常用**德勤标准**：base_score=600、PDO=20、base_odds=50。

```
Score = A − B · ln(odds)
其中：
  B = PDO / ln2 ≈ 20 / 0.6931 ≈ 28.85      # 分数斜率
  A = base_score − B · ln(base_odds) = 600 − 28.85 × ln(50) ≈ 487.1
```
- PDO（Points to Double the Odds）：odds 每翻一倍，分数下降 20 分
- base_odds=50：600 分对应 好:坏 = 50:1（违约概率约 1/51 ≈ 2%）
- 每个变量的分箱分值：
```
Score_j = −(β_j · WOE_i + β₀/k) × B + A/k     # k = 变量个数
```
- 打分：`scorecard_ply` 对**原始值**逐箱查表加总，无需再算 WOE

### 5.7 LightGBM（对照模型，v2）
梯度提升决策树（GBDT）：串行训练多棵树，每棵拟合前面所有树的残差梯度。

| 参数 | 取值 | 含义 |
|---|---|---|
| `objective` | binary | 二分类负对数损失 |
| `learning_rate` | 0.05 | 每棵树的贡献步长，小 = 稳但需更多树 |
| `num_leaves` | 31 | 单棵树最大叶子数（模型复杂度核心开关） |
| `min_data_in_leaf` | 50 | 叶子最小样本数，防过拟合 |
| `feature_fraction` | 0.8 | 每棵树随机抽 80% 特征（列采样） |
| `bagging_fraction` / `bagging_freq` | 0.8 / 5 | 每 5 轮随机抽 80% 样本（行采样） |
| `scale_pos_weight` | 负样本数/正样本数 | 违约类加权，替代过采样 |
| `early_stopping` | 30 | 验证集 30 轮无提升即停止（防过训练） |
| `num_boost_round` | 500 | 最多 500 棵树 |

定位：**不做主模型**（黑箱、监管难解释），只作对照组——若 LGBM 远超 LR+WOE，说明线性假设丢信息；两者接近则证明评分卡方案足够。本项目实测 LR AUC≈0.93 vs LGBM≈0.95，验证了 LR+WOE 的合理性。

### 5.8 SHAP（SHapley Additive exPlanations）
源自合作博弈论的 Shapley 值：把一次预测的输出**公平分摊**到每个特征：
```
φ_i = Σ_S [ |S|!(k−|S|−1)! / k! ] · ( v(S∪{i}) − v(S) )
f(x) = base + Σ φ_i               # 加性分解，可精确对账
```
- `TreeExplainer`：针对树模型的精确多项式时间算法
- 汇总方式：`mean(|SHAP|)` 按特征取绝对值平均 → 全局重要性排序
- 本项目 top 特征（4 年子集）：ROA_3y_avg > ROE > IndustryCode > FirmAge > ROA_3y_std

### 5.9 简化 SHAP / 系数重要性（LR 专用）
对 LR+WOE，每个特征对 log-odds 的边际贡献恰为 `coef_j × x_j`，故用：
```
importance_j = |β_j|
```
排序等价于"每变 1 单位 WOE 对违约 log-odds 的影响幅度"。是真实 SHAP 在线性模型下的解析特例，零额外计算成本。

## 六、模型评估指标（含公式）

### 6.1 混淆矩阵基础
设 1 = 违约（坏）、0 = 正常（好）：
```
TPR（真阳率/召回）= TP / (TP + FN)      # 抓住了多少违约户
FPR（假阳率）    = FP / (FP + TN)      # 误伤了多少好客户
```

### 6.2 ROC 与 AUC
- ROC 曲线：以 FPR 为横轴、TPR 为纵轴，遍历所有阈值画出的一条曲线
- AUC（Area Under Curve）：
```
AUC = ∫₀¹ TPR d(FPR)
    = P( 随机取一个违约户的得分 > 随机取一个好客户的得分 )
```
- 0.5 = 随机猜；0.7–0.8 可接受；0.8–0.9 优秀；>0.9 需警惕泄漏
- 本项目：German Credit 测试集 ≈0.61（基线弱）；CSMAR 面板 ≈0.93（ST 代理标签的可预测性强）

### 6.3 KS（Kolmogorov-Smirnov 统计量）
```
KS = max_t | TPR(t) − FPR(t) |
```
好坏客户累计分布的**最大分离距离**。风控业界最常用：
- < 0.2 无区分度；0.2–0.3 弱；**0.3+ 可用**；0.4+ 良好；>0.75 警惕泄漏

### 6.4 Gini（基尼系数，又称 Accuracy Ratio）
```
Gini = 2 × AUC − 1
```
ROC 曲线与对角线之间面积的两倍。与 AUC 完全等价，只是刻度不同（−1 到 1）。

### 6.5 PSI（Population Stability Index，群体稳定性指标）
```
PSI = Σ_i ( a_i − e_i ) · ln( a_i / e_i )

e_i = 基准期（训练集）落入第 i 箱的占比
a_i = 当前期（测试集）落入第 i 箱的占比
```
实现细节：按训练集分数的**十分位**切箱，空箱以 0.0001 平滑防 ln(0)。

| PSI | 判定 |
|---|---|
| < 0.1 | 稳定 |
| 0.1–0.25 | 需关注/复核 |
| > 0.25 | 严重漂移，模型不可信 |

⚠️ 本项目语义提醒：计算的是 **train_proba vs test_proba**（样本内 vs 样本外），不是严格的"上线后 vs 训练期"跨期监控；真正的分布稳定性验证需要 OOT 样本。

### 6.6 CSI（Characteristic Stability Index，特征稳定性指标）
CSI = 单个特征级别的 PSI。公式同上，把"分数分布"换成"某特征的分布"。用于定位"漂移发生在哪个变量上"。

## 七、模型验证方法

### 7.1 随机划分 + 分层抽样（Stratified Split）
```
train_test_split(df, test_size=0.3, random_state=42, stratify=y)
```
分层保证训练/测试集中违约比例一致；`random_state=42` 固定种子保证可复现。

### 7.2 Expanding Window CV（扩张窗口时序交叉验证，v2）
针对面板数据（同年多公司 + 同公司多年）设计的防穿越验证：

```
fold t：train = { year ≤ t−1 }，test = { year == t }，t 从第 4 年开始
即：2018 训练 → 测 2019；2018-19 训练 → 测 2020；……窗口逐年扩张
```

| 对比项 | 随机 K 折 | Expanding Window |
|---|---|---|
| 是否用未来数据 | 会（未来年份样本混入训练） | 不会 |
| 模拟上线场景 | 否 | **是**（用历史预测未来） |
| 得到的 AUC | 偏乐观 | 更接近真实 |

- 输出 `cv_per_fold`：每年一行的 auc/ks/gini/default_rate → 可观察**逐年衰减**（时间衰减是信用模型的天性）
- 性能优化：首窗分箱（bins）在后续 fold 复用，省约 3 分钟/fold；列对齐用 `reindex(fill_value=0)`
- 支持断点续跑（`resume_from_csv`）

### 7.3 OOT（Out-of-Time）验证
与上同源的思想：用**时间上更晚**的数据做验证集，而非随机抽行。Expanding Window CV 的每个 fold 本质上都是 OOT 检验。

## 八、合规护栏（Guardrails）

`GuardrailResult` 数据类：`passed / metrics / warnings / requires_human_review / rationale`。

| 指标 | 警告线（→ 人工复核 HITL） | 拒绝线（CRITICAL，禁止上线） |
|---|---|---|
| KS | < 0.3 | < 0.2 |
| AUC | < 0.7 | — |
| PSI | > 0.1 | > 0.25 |

阈值集中在 `config/default_config.yaml` 的 `guardrails` 段，可按业务调宽严。

## 十、模型结果字段（TrainingResult / 节点输出）

| 字段 | 类型 | 内容 |
|---|---|---|
| `eda` | dict | 行列数、target 分布、缺失率、dtype、数值/类别统计 |
| `metrics` | dict | `train` / `test` 嵌套 + 顶层 = 测试集 {auc, ks, gini, psi} |
| `scorecard` | dict[var, DataFrame] | 每变量每箱：bin 区间、woe、系数、分值 points |
| `scored_test` | DataFrame | 测试集总分（`score` 列），可画分布直方图 |
| `guardrail` | GuardrailResult | 护栏判定（passed/warnings/rationale） |
| `model` / `bins` | LR 对象 / dict | 模型与分箱定义（评分卡的两个原料） |
| `train_proba` / `test_proba` | ndarray | 违约概率，PSI 与 KS 的原料 |
| `feature_importance` | DataFrame | feature / coef / abs_coef / rank（LR 简化 SHAP） |
| `cv_per_fold` | DataFrame | [year, n_train, n_test, default_rate, auc, ks, gini, error] |
| `cv_mean` | dict | {auc, ks, gini, n_folds} 跨期均值 |
| `lgbm_model` / `lgbm_metrics` | — | 对照模型及其 train/test 指标 |
| `lgbm_shap_importance` | DataFrame | feature / mean_abs_shap / rank |
